# Qonnect — Démo statique enrichie

Cette version est une démonstration simple du concept Qonnect : un système de management qualité interconnecté.

## Contenu

- `index.html` : interface principale
- `assets/` : styles + logo
- `database/` : données JSON simulant un SMQ
- `docs/` : documentation produit

## Objectif

Permettre une présentation rapide du produit sans backend ni framework.

## Lancer la démo

Ouvrir simplement `index.html` dans un navigateur.
